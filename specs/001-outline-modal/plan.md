# Implementation Plan: Presenter Outline Modal

**Branch**: `001-outline-modal` | **Date**: 2026-06-17 | **Spec**: [spec.md](spec.md)

**Input**: Feature specification from `specs/001-outline-modal/spec.md`

## Summary

Add a hidden "m"-key-triggered outline modal to the deck. The modal lists every entry
in the active variant in order (section number, label, flow badge), supports mouse
click and Up/Down/Enter keyboard selection, and closes on "m", Escape, or backdrop
click. No visible trigger exists in the deck UI. Entry data comes entirely from the
variant manifest — no hardcoded strings in the component.

## Technical Context

**Language/Version**: JavaScript (ES2022), React 19, Vite 8

**Primary Dependencies**: React (useState, useEffect, useRef, useCallback) — no new deps

**Storage**: N/A

**Testing**: Vitest (existing suite)

**Target Platform**: Browser, projected screen (16:10, 1080p target)

**Project Type**: Single-page presentation app

**Performance Goals**: Modal open/close must be imperceptible — no layout thrash, no
network calls. Entry list is at most ~15 items; no virtualization needed.

**Constraints**: All styles in src/index.css (no inline style props). Manifest is the
only source of entry data. Must not break existing keyboard navigation.

**Scale/Scope**: ~15 entries max per variant. One new component, one new CSS block,
targeted changes to App.jsx and variants.js.

## Phase 0: Research

**Status**: Complete — see [research.md](research.md)

Key decisions resolved:

- **Title derivation**: Add `label` field to every slide entry in variants.js (matches
  the existing flow entry pattern). See data-model.md for the full label table.
- **Component location**: `src/outline/OutlineModal.jsx` (follows feature-area directory
  convention: flow/, picker/, slides/, outline/).
- **Keyboard ownership**: "m" toggle + Escape-while-open handled in Deck's global
  `onKey`; Up/Down/Enter list navigation handled inside OutlineModal via `onKeyDown`.
- **Focus management**: `focusedIndex` state + ref array + programmatic `focus()` on
  change. All buttons `tabIndex={-1}`.
- **Backdrop click**: Full-viewport backdrop div with `onClick={onClose}`; panel stops
  propagation.
- **"m" key conflict**: No conflict — current handler only uses arrow keys, Space,
  Escape, and Home.
- **Styling**: All new classes prefixed `outline-` in src/index.css.

## Phase 1: Design & Contracts

**Status**: Complete

### Entry label additions (variants.js)

All entry constants gain a `label` field. See [data-model.md](data-model.md) for the
complete table. The `withSections` function passes `label` through unchanged (it only
strips `numbered` and adds `section`).

### OutlineModal component design

See [contracts/outline-modal.md](contracts/outline-modal.md) for the full interface.

**Render tree**:

```
div.outline-backdrop  [onClick=onClose]
  div.outline-panel   [onKeyDown=handleKey, role="dialog", aria-modal="true"]
    ul.outline-list   [role="listbox", aria-label="Slide outline"]
      button.outline-entry x N  [role="option", tabIndex=-1, data-type, data-focused?]
        span.outline-section-num   ("01" | "")
        span.outline-title         (entry.label)
        span.outline-flow-badge?   ("interactive" — flow entries only)
```

**State**: `focusedIndex` (number, starts at 0)

**Refs**: `buttonRefs` — array of refs, one per entry, for programmatic focus

### App.jsx changes

1. Add `outlineOpen` state to `Deck`.
2. In `onKey`: handle `"m"` first (toggle, return); when `outlineOpen`, suppress arrow
   keys and space, and consume Escape before the flow handler runs.
3. Render `<OutlineModal>` conditionally when `outlineOpen` is true, passing `entries`,
   `onNavigate` (calls `navigateTo(i)` then `setOutlineOpen(false)`), and
   `onClose` (`() => setOutlineOpen(false)`).

### CSS additions (src/index.css)

New block at end of file. All sizes in `vmin` or `em`. Contrast >= 4.5:1 for all text.
IBM Plex Mono for `.outline-section-num` (section labels follow brand label convention).

| Class                              | Purpose                                                   |
| ---------------------------------- | --------------------------------------------------------- |
| `.outline-backdrop`                | position:fixed; inset:0; semi-transparent dark background |
| `.outline-panel`                   | Centered container; light background; border-radius       |
| `.outline-list`                    | list-style:none; margin/padding reset                     |
| `.outline-entry`                   | Full-width button; flex row; gap; cursor:pointer          |
| `.outline-entry[data-focused]`     | Highlight background on keyboard-focused entry            |
| `.outline-entry[data-type="flow"]` | Subtle visual distinction for the flow entry              |
| `.outline-section-num`             | Monospace; dim color; fixed width for alignment           |
| `.outline-title`                   | Normal weight; readable size                              |
| `.outline-flow-badge`              | Small pill; accent color; "interactive" label             |
